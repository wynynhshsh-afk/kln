# ربات مدیریت فوروارد (کانال↔کانال / گروه↔کانال / گروه↔گروه)

یک ربات مدیریتی («ربات اصلی») که فقط پنل تنظیمات است و خودش هیچ پیامی فوروارد
نمی‌کند. از داخل آن چهار دسته تعریف شده:

- 📡 فوروارد کانال به کانال
- 📡 فوروارد گروه به کانال
- 📡 فوروارد کانال به گروه
- 📡 فوروارد گروه به گروه

داخل هر دسته می‌توانی چند **منبع (route)** اضافه کنی. هر منبع یعنی:
یک ربات با توکن مخصوص خودش (از @BotFather) + یک چت مبدأ + یک چت مقصد.
یعنی اگر مثلاً در «کانال به کانال» ۵ منبع بخواهی، باید ۵ توکن ربات جدا بدهی؛
هرکدام دقیقاً یک مبدأ و یک مقصد دارند.

## ۱. ساخت جدول در Supabase

فایل `schema.sql` را باز کنید و کوئری‌های بخش ۱ و ۲ (ساخت جدول `settings` و
`routes`) را در SQL editor پروژه Supabase اجرا کنید.

سپس از بخش Project Settings → API، مقدار `Project URL` و `service_role key` را
بردارید (همان `SUPABASE_URL` و `SUPABASE_KEY`).

## ۲. ساخت ربات مدیریتی در تلگرام

با @BotFather یک ربات بسازید (این همان ربات اصلی/پنل است) و توکن آن را بردارید.
آیدی عددی خودتان (و هر ادمین دیگری که می‌خواهید) را از @userinfobot بگیرید؛
این‌ها همان مقادیر `ADMINS` هستند (با کاما از هم جدا می‌شوند، مثلا `111,222`).

برای هر منبعی که بعداً می‌خواهید اضافه کنید، یک ربات دیگر هم از @BotFather
بسازید و توکنش را کنار بگذارید (این توکن‌ها را داخل خود پنل ربات وارد می‌کنید،
نه در متغیرهای محیطی).

## ۳. دیپلوی روی Render

1. این پوشه را در یک ریپوی گیت‌هاب push کنید.
2. در Render یک **Web Service** جدید از نوع Python بسازید (یا از همین `render.yaml` استفاده کنید).
3. Build command: `pip install -r requirements.txt`
4. Start command: `python main.py`
5. متغیرهای محیطی زیر را ست کنید:
   - `BOT_TOKEN` → توکن ربات مدیریتی (پنل)
   - `ADMINS` → آیدی عددی ادمین‌ها با کاما جدا شده، مثلا `111,222`
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
   - `WEBHOOK_URL` → آدرس سرویس روی Render، مثلا `https://tg-forward-bot.onrender.com`
   - `WEBHOOK_SECRET` → یک رشته دلخواه (مثلا `forwardbot`)
   - `PORT` → پیش‌فرض `8443` (Render خودش این متغیر را ست می‌کند)

بعد از بالا آمدن سرویس، برنامه به‌صورت خودکار وبهوک ربات مدیریتی را روی
`WEBHOOK_URL/WEBHOOK_SECRET` تنظیم می‌کند؛ نیازی به تنظیم دستی نیست.
ربات‌های هر منبع (route) به‌صورت polling در پس‌زمینه‌ی همین سرویس اجرا می‌شوند.

## ۴. اضافه‌کردن یک منبع جدید

1. در چت خصوصی با ربات مدیریتی دستور `/start` را بزنید.
2. یکی از چهار دسته را باز کنید (مثلا «فوروارد کانال به کانال»).
3. «➕ افزودن منبع جدید» را بزنید و توکن یک ربات تازه (از @BotFather) را بفرستید.
4. چت مبدأ را مشخص کنید: یک پیام از آن چت فوروارد کنید، یا آیدی عددی/یوزرنیم آن
   را بفرستید. **قبلش باید همان ربات تازه را داخل آن چت عضو (برای گروه) یا
   ادمین (برای کانال) کرده باشید** — کانال‌ها فقط برای ادمین‌ها آپدیت پست
   می‌فرستند، پس اگر مبدأ کانال است حتماً ربات را ادمین کنید.
5. چت مقصد را هم به همین ترتیب مشخص کنید. ربات باید در مقصد هم ادمین/عضو با
   اجازه‌ی ارسال پیام باشد.
6. با ثبت مقصد، منبع خودکار فعال می‌شود و از آن پس هر پیام جدید در مبدأ، بعد
   از تاخیر تنظیم‌شده (پیش‌فرض ۶ ثانیه)، به مقصد فوروارد می‌شود.

از همان منوی هر دسته می‌توانی هر منبع را غیرفعال/فعال یا حذف کنی.

## نکات

- فقط ادمین‌های تعریف‌شده در `ADMINS` به پنل ربات دسترسی دارند.
- اگر مبدأ **گروه** است، ربات باید عضو گروه باشد و Privacy Mode آن در
  @BotFather خاموش باشد تا بتواند پیام‌های معمولی گروه را ببیند.
- اگر مبدأ **کانال** است، ربات باید در آن کانال ادمین باشد (کانال‌ها اصلاً
  رویداد پیام را برای غیرادمین‌ها ارسال نمی‌کنند).
- تلگرام رویداد «حذف پیام» را برای بات‌ها ارسال نمی‌کند؛ به همین دلیل تشخیص
  حذف با روش «تلاش برای فوروارد بعد از تاخیر» انجام می‌شود؛ اگر پیام در همان
  بازه پاک شده باشد این تلاش با خطا مواجه و نادیده گرفته می‌شود.
- برای افزایش این تاخیر مقدار «تاخیر ارسال» را از منوی اصلی پنل زیاد کنید
  (بین همه‌ی منابع مشترک است).
